# Frontend - Clinic Website & Patient Portal

## Overview
Modern Next.js frontend application for Dr. Kalekar Star Clinic with SEO optimization, patient education flow, and comprehensive appointment management.

## Features
- 🎯 **SEO Optimized** - Ready for Google ranking with structured data
- 📱 **Mobile Responsive** - Works perfectly on all devices
- 🏥 **Patient Education Flow** - Interactive guided symptom selection
- 💼 **Premium Landing Page** - Testimonials, FAQ, trust badges
- 📅 **Online Booking** - Multiple booking options (call, WhatsApp, portal)
- 🏥 **Clinic Information** - Complete services, doctors, contact details
- 🔐 **Authentication** - Secure patient and doctor portals
- 📋 **Prescription Management** - Digital prescriptions and printing
- 📱 **PWA Support** - Installable web app with push notifications

## Pages
- **Home** - Premium landing page with hero section and features
- **About** - Clinic history, mission, and values
- **Doctors** - Detailed doctor profiles and specializations
- **Services** - Complete list of orthopaedic and women's health services
- **Contact** - Location, hours, and contact information
- **Patient Portal** - Dashboard, appointments, prescriptions
- **Doctor Portal** - Consultations, patient history, queue management
- **Receptionist Portal** - Appointment booking and patient management

## Technologies
- Next.js 14 with App Router
- TypeScript for type safety
- Tailwind CSS for modern styling
- Lucide React for icons
- SWR for data fetching
- React Hook Form for forms

## Setup
```bash
npm install
npm run dev
```

## Environment Variables
Create `.env.local` with:
```
NEXT_PUBLIC_API_URL=http://localhost:3001
GOOGLE_CLIENT_ID=your-google-client-id
```

## SEO Features
- Structured data (JSON-LD) for rich snippets
- Optimized meta tags and Open Graph
- Robots.txt and sitemap.xml
- Semantic HTML5 structure
- Fast loading performance

## Deployment
Ready for deployment on Vercel, Netlify, or Railway with automatic SEO optimization.
